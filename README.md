# SSH Connection Monitor

A Bash script that analyzes SSH login activity from Linux authentication logs.

## Features

- Counts successful SSH logins
- Counts failed SSH login attempts
- Reads Linux authentication logs

## Technologies Used

- Bash
- Linux
- OpenSSH
- grep

## Example Output

===== SSH Connection Monitor =====

Successful SSH Logins: 9

Failed SSH Logins: 5

## Usage

chmod +x monitor.sh
./monitor.sh
